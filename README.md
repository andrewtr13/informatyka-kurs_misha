# Курс інформатики: від біта до штучного інтелекту

50 занять, два рази на тиждень. Кожне заняття — інтерактивна сторінка з теорією, практичними завданнями (зокрема на Python), тестом і челенджем на тиждень.

- `index.html` — головна сторінка курсу з програмою і прогресом
- `lessons/` — заняття

## Як проходити

1. Відкрий головну сторінку курсу і натисни «Почати».
2. Завдання на сторінці перевіряються одразу.
3. Завдання на Python виконуй у себе (IDLE або інший редактор) і запускай перевірку з кінця кожного прикладу.
4. Якщо застряг, спочатку відкрий підказки, а розв'язок дивись тільки в крайньому разі.
