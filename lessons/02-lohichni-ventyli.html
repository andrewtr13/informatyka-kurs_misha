Два вимикачі і лампочка

Транзистор — це вимикач, яким керує не палець, а електричний сигнал. Подивимось, що можна зробити лише з двома вимикачами. Їх можна з'єднати двома способами: послідовно (один за одним) або паралельно (поруч, дві окремі доріжки).

Пограйся з обома схемами і подумай: коли світиться лампочка?

  • Послідовно: лампочка світиться, тільки якщо увімкнені A і B.
  • Паралельно: лампочка світиться, якщо увімкнений A або B (або обидва).

Ці дві схеми звуться логічними вентилями І та АБО. Англійською AND та OR.

Як додати два біти

Тепер найважливіше: як вентилі рахують. Розберемо по кроках.

А. Згадай додавання в стовпчик

Як ти додаєш 27 + 15 на папері? Справа наліво, по одному стовпчику:

1 ← «1 в умі» 2 7 + 1 5 ───── 4 2
  • Правий стовпчик: 7 + 5 = 12. Цифра 12 у клітинку не влазить, тому пишемо 2, а 1 тримаємо в умі і переносимо в наступний стовпчик.
  • Лівий стовпчик: 2 + 1 + 1 з уму = 4.

Отже, в кожному стовпчику виходять дві речі: цифра, яку пишемо, і цифра, яку переносимо далі.

Б. Те саме в двійковій

У двійковій системі є тільки цифри 0 і 1. Додамо два біти, всього чотири варіанти:

  • 0 + 0 = 0. Пишемо 0, в умі 0.
  • 0 + 1 = 1. Пишемо 1, в умі 0.
  • 1 + 0 = 1. Пишемо 1, в умі 0.
  • 1 + 1 = два. Але цифри «2» у двійковій немає! Два записується як 10 (згадай заняття 1: ваги 2 і 1). Тому пишемо 0, а 1 в умі. Так само як у десятковій 5 + 5 = 10: пишемо 0, 1 в умі.

В. Знаходимо вентилі

Запишемо ці чотири варіанти в таблицю. Цифру, яку пишемо, назвемо сума (S), а цифру в умі перенос (C), від англійського carry, «нести». Поруч поставимо таблиці двох вентилів з кроку 2:

ABв умі Cпишемо SA І BA ВИКЛ. АБО B
000000
010101
100101
111010

Порівняй стовпчики однакового кольору зверху вниз:

  • «В умі» (0, 0, 0, 1) збігається з вентилем І. Логічно: переносимо, тільки коли обидва біти дорівнюють 1.
  • «Пишемо» (0, 1, 1, 0) збігається з вентилем ВИКЛЮЧНЕ АБО. Пишемо 1, тільки коли біти різні.

Чотирибітний суматор

Тепер додамо довгі числа. Візьмемо 6 + 3. У двійковій 6 = 0110, 3 = 0011. Додаємо в стовпчик справа наліво, так само як 27 + 15 вище:

1 1 ← в умі 0 1 1 0 (6) +0 0 1 1 (3) ──────── 1 0 0 1 (9)
  • 1-й стовпчик (справа): 0 + 1 = 1. Пишемо 1, в умі нічого.
  • 2-й: 1 + 1 = 10. Пишемо 0, 1 в умі.
  • 3-й: 1 + 0 + 1 з уму = 10. Пишемо 0, 1 в умі.
  • 4-й: 0 + 0 + 1 з уму = 1. Пишемо 1.

Вийшло 1001 = 8 + 1 = 9. Правильно!

Зверни увагу: у 3-му стовпчику довелося додавати вже три біти: два біти чисел і один «з уму». Півсуматор так не вміє. Для цього є повний суматор (ПС): він складається з двох півсуматорів і додає три біти.

Поставимо чотири повних суматори в ряд, по одному на стовпчик, і передаватимемо перенос справа наліво. Вийде калькулятор для чисел від 0 до 15. Клацай біти чисел A і B. Спершу набери 6 + 3 і подивись, чи збігається з прикладом.

Збери вентиль з інших

Деякі вентилі можна зібрати з інших. Схема нижче має три вентилі: перші два отримують A і B, третій об'єднує їхні результати. Обери вентилі так, щоб уся схема працювала як потрібно. Зелені рядки таблиці вже збігаються з ціллю, червоні ще ні.

Факт. Бортовий комп'ютер «Аполлона», який доставив людей на Місяць, був зібраний з вентилів лише одного типу: НЕ-АБО (NOR). Їх було кілька тисяч. З одного NOR можна зібрати будь-який інший вентиль, а отже і цілий комп'ютер.

7.2 · Півсуматор

Функція може повертати два значення одразу: return s, c. Отримати їх можна так: s, c = half_adder(1, 1). Заповни два пропуски. Згадай крок 4: який вентиль дає суму, а який перенос?

def half_adder(a, b):
    s = a ___ b     # сума: 1, коли біти різні
    c = a ___ b     # перенос: 1, коли обидва біти 1
    return s, c


# ---- перевірка ----
def check(got, expected):
    if got == expected:
        print("OK:", got)
    else:
        print("ПОМИЛКА: вийшло", got, "а треба", expected)

check(half_adder(0, 0), (0, 0))
check(half_adder(0, 1), (1, 0))
check(half_adder(1, 0), (1, 0))
check(half_adder(1, 1), (0, 1))
Підказка

Один пропуск дорівнює ^, другий &. Який де?

Розв'язок

s = a ^ b і c = a & b.

7.3 · Повний суматор з двох півсуматорів

Допиши цей код у той самий файл, нижче за half_adder, бо повний суматор використовує півсуматор. Спершу додаємо A і B, потім до результату додаємо перенос, що прийшов справа. Якщо перенос виник хоча б на одному з кроків, він іде далі.

def full_adder(a, b, c_in):
    s1, c1 = half_adder(a, b)       # крок 1: A + B
    s, c2 = half_adder(s1, c_in)    # крок 2: + перенос справа
    c_out = c1 ___ c2               # перенос, якщо він був хоч на одному кроці
    return s, c_out


check(full_adder(0, 0, 1), (1, 0))
check(full_adder(1, 0, 1), (0, 1))
check(full_adder(1, 1, 0), (0, 1))
check(full_adder(1, 1, 1), (1, 1))
Підказка

Перенос іде далі, якщо c1 дорівнює 1 АБО c2 дорівнює 1. Який знак означає АБО?

Розв'язок

c_out = c1 | c2

7.4 · Калькулятор з вентилів

Цей код повністю готовий. Допиши його в той самий файл і запусти. Функція add розкладає числа на біти й додає їх ланцюжком повних суматорів, так само як на кроці 5.

def to_bits(n, bits):
    result = []
    for i in range(bits):
        result.append(n % 2)    # наймолодший біт першим
        n = n // 2
    return result


def add(x, y, bits):
    a = to_bits(x, bits)
    b = to_bits(y, bits)
    carry = 0
    total = 0
    for i in range(bits):
        s, carry = full_adder(a[i], b[i], carry)
        total = total + s * 2 ** i
    print(x, "+", y, "=", total, "   перенос, що не вмістився:", carry)


add(5, 3, 4)
add(7, 9, 4)

Завдання.

  • Чому 7 + 9 вийшло 0? Згадай крок 5.
  • Що треба змінити, щоб 7 + 9 порахувалося правильно?
  • Порахуй своїм калькулятором 200 + 55 і 200 + 56 з bits = 8. Що сталося і чому саме на 256?
Відповіді

16 у двійковій — це 10000, п'ять бітів. У 4 біти вміщуються тільки чотири нулі, а одиниця «вилітає» в перенос. Якщо написати add(7, 9, 8), буде 16. А 200 + 56 = 256 не вміщується у 8 бітів, бо найбільше 8-бітне число 255 (пам'ятаєш з заняття 1?).
