Чому саме 0 і 1

Процесор складається з транзисторів. Це крихітні вимикачі: струм або йде, або ні. Сучасний чип вміщує десятки мільярдів таких вимикачів на площі з ніготь.

Можна було б зробити транзистор, який розрізняє 10 рівнів напруги, і рахувати в звичній десятковій системі. Але тоді найменша перешкода (нагрів, наводка, старіння) перетворить «7» на «6». Два стани розрізнити легко: «є струм» чи «немає». Тому комп'ютери двійкові. Це питання надійності, а не обмеження.

Один такий вимикач зберігає 1 біт: 0 або 1. Вісім бітів утворюють байт.

Факт. Бортовий комп'ютер «Вояджера-1», запущеного в 1977 році, має близько 70 КБ пам'яті. Це менше, ніж займає одна фотографія на твоєму телефоні. Він досі працює і передає дані з-за меж Сонячної системи.

Вісім лампочок = один байт

У десятковому числі 365 кожна цифра має «вагу»: 3 сотні, 6 десятків, 5 одиниць. Кожна позиція вдесятеро важча за попередню.

У двійковій системі все так само, тільки кожна позиція удвічі важча: 1, 2, 4, 8, 16, 32, 64, 128. Лампочка горить, отже її вага додається до числа.

Увімкни лампочки так, щоб вийшло число. Коли влучиш, з'явиться наступне.

Легенда про шахи і зерно

За легендою, винахідник шахів попросив у правителя нагороду: одну зернину на першу клітинку дошки, дві на другу, чотири на третю, і так далі, щоразу вдвічі більше. Правитель засміявся з такої скромності. Дарма.

Подивись на рядок «Разом у двійковій»: там самі одиниці. Сума 1 + 2 + 4 + … + 263 дорівнює 264 − 1. Це найбільше число, яке вміщується в 64 біти. Саме стільки бітів обробляє за раз процесор твого комп'ютера, тому його називають 64-бітним.

Масштаб. Якщо одна зернина важить 0,05 г, то вся нагорода важить приблизно 920 мільярдів тонн. Людство вирощує близько 790 мільйонів тонн пшениці на рік, тож для правителя це понад тисячу років світового врожаю.

Крок 4 · інтерактив · 15 хв

Шахова дошка як одне число

На дошці 64 клітинки, і в 64-бітному числі теж 64 біти. Шахові програми, наприклад Stockfish, користуються цим збігом: позиції фігур одного типу зберігаються як одне число, яке називається бітборд (bitboard). Клітинка a1 відповідає біту 0, b1 — біту 1, … h1 — біту 7, a2 — біту 8, і так до h8, якій відповідає біт 63.

Навіщо це потрібно? Процесор оперує 64-бітним числом за одну дію. Тому відповідь на питання «чи атакує хтось цю клітинку?» займає мільярдні частки секунди.

Літери теж числа

Комп'ютер не знає, що таке літера «А». Люди домовилися про таблицю: кожен символ має свій номер. Для латиниці є стара таблиця ASCII, де «A» = 65, «B» = 66 і так далі. Для всіх мов світу, включно з українською, шахами ♞ і емодзі 🚀, існує Юнікод зі 150 тисячами символів. Тому українська літера займає 2 байти, а емодзі 4.

Крок 6 · головоломка · 15 хв

Послання в космос

У 1974 році радіотелескоп Аресібо відправив до зоряного скупчення M13 повідомлення з 1679 бітів. Як інопланетянам здогадатися, що це картинка і якої вона ширини? Учені вибрали число, яке розкладається на прості множники лише одним способом: 1679 = 23 × 73. Розумна істота, яка знає математику, розкладе 1679, складе біти в прямокутник 23 × 73 і побачить малюнок: людину, ДНК, Сонячну систему.

Нижче наше власне повідомлення. Це рядок бітів без жодних підказок. Розшифруй його.

Завдання 3

Скільки бітів у повідомленні? Розклади це число на прості множники і знайди ширину, при якій з'являється малюнок.

Практика на Python

Відкрий IDLE або будь-який редактор, у якому пишеш на Python. Головне правило: не використовуй вбудовані bin() та int(s, 2). Ми хочемо зрозуміти, як вони працюють усередині. Після кожного завдання запусти перевірку: якщо все правильно, програма надрукує «Усе працює!».

7.1 · Двійкове → десяткове

Напиши функцію from_binary(s). Вона отримує рядок на кшталт "1101" і повертає число 13.

def from_binary(s):
    # твій код тут
    ...

# перевірка
assert from_binary("1101") == 13
assert from_binary("0") == 0
assert from_binary("11111111") == 255
assert from_binary("1000000") == 64
print("Усе працює!")
Підказка 1

Пройди по рядку зліва направо. Коли дописуєш нову цифру справа, усе, що вже є, зсувається вліво і стає вдвічі більшим.

Підказка 2

Тримай змінну result = 0. Для кожного символу c роби result = result * 2 + (1 якщо c == "1", інакше 0).

Розв'язок (спочатку спробуй сам!)
def from_binary(s):
    result = 0
    for c in s:
        result = result * 2 + int(c)
    return result

Підказка 1

n % 2 дає останню (наймолодшу) двійкову цифру. n // 2 відкидає її.

Підказка 2

Повторюй, поки n > 0: дописуй остачу на початок рядка. Окремо оброби випадок n == 0.

Розв'язок (спочатку спробуй сам!)
def to_binary(n):
    if n == 0:
        return "0"
    s = ""
    while n > 0:
        s = str(n % 2) + s
        n = n // 2
    return s

7.3 · Розшифруй послання

Напиши функцію show(bits, width), яка друкує рядок бітів як картинку: 1 → #, 0 → пробіл, по width символів у рядку. Потім напиши функцію factors(n), яка повертає список простих множників числа. Застосуй обидві до повідомлення нижче (воно інше, ніж на кроці 6!).


        
Підказка
Зріз bits[i:i+width] дає один рядок картинки. Для множників ділі n на d = 2, 3, 4, …, поки ділиться без остачі.

        
Розв'язок (спочатку спробуй сам!)
def show(bits, width):
    for i in range(0, len(bits), width):
        row = bits[i:i + width]
        print(row.replace("1", "#").replace("0", " "))

def factors(n):
    result = []
    d = 2
    while n > 1:
        while n % d == 0:
            result.append(d)
            n //= d
        d += 1
    return result

Куди стрибає кінь

    

      
Напиши функцію knight_moves(square). Вона отримує номер клітинки від 0 (a1) до 63 (h8) і повертає бітборд: одне число, в якому увімкнені біти всіх клітинок, куди може стрибнути кінь. Пам'ятай про краї дошки: кінь з a1 не може стрибнути «вліво».

    

    
def knight_moves(square):
    ...

assert knight_moves(6) == 10489856   # кінь на g1: e2, f3, h3
assert knight_moves(0) == 132096     # кінь на a1: b3, c2

Перетвори номер на рядок і стовпчик: row = square // 8, col = square % 8. Кінь змінює їх на (±1, ±2) або (±2, ±1). Пропускай ходи, які виходять за межі 0..7. Для кожного дозволеного ходу вмикай біт: result |= 1 << (r * 8 + c).
