Файли, папки і дерево

Файл — це шматок даних на диску, який має ім'я. Фото, пісня, програма, документ — усе це файли. Для диска вони однакові: просто послідовності байтів (пам'ятаєш, усе є числами).

Папка — це контейнер для файлів та інших папок. Папки вкладаються одна в одну, і виходить дерево: на самому верху диск C: (корінь), від нього гілки-папки, а на кінцях листки-файли. Тільки програмісти малюють це дерево догори ногами: корінь угорі.

Ось спрощена копія того, що є на твоєму комп'ютері. Клацай на папки, щоб відкрити їх. Угорі адресний рядок показує, де ти зараз.

Шлях до файлу — це його адреса

Щоб знайти файл, треба знати, через які папки до нього йти. Цей маршрут зветься шлях. Наприклад:

C:\Users\Misha\Documents\Інформатика\Заняття 03\зірка8.txt

Читається він так: диск C: → папка Users (користувачі) → папка користувача Misha → Documents (документи) → і так далі до самого файлу. Між папками ставиться зворотна риска \. Майже як адреса: країна, місто, вулиця, будинок, квартира.

У Windows англійські назви системних папок Провідник показує українською: Documents як «Документи», Pictures як «Зображення», Downloads як «Завантаження». Але в шляху вони залишаються англійськими.

Тепер на справжньому комп'ютері

  1. Відкрий Провідник (Win + E) і зайди в папку «Документи».
  2. Клацни на порожнє місце в адресному рядку вгорі (або натисни Ctrl + L). Замість гарних назв з'явиться справжній шлях, наприклад C:\Users\Misha\Documents. Якщо в шляху є OneDrive, твої документи ще й зберігаються в хмарі Microsoft.
  3. Можна навпаки: надрукуй шлях в адресному рядку, натисни Enter, і Провідник відкриє цю папку. Спробуй C:\Windows.
Крок 3 · розширення і безпека · 15 хв

Що означає .jpg, .exe і .txt

Остання частина імені після крапки зветься розширення. За ним Windows вирішує, якою програмою відкрити файл: .jpg і .png — картинки, .mp3 — музика, .txt — текст, .py — програма на Python, .docx — документ Word. А .exe означає програму, яка запуститься і виконає свої команди.

Проблема: Windows за замовчуванням приховує розширення. Шахраї цим користуються. Файл фото.jpg.exe виглядає як фото.jpg, а насправді це програма, яка може бути вірусом.

Увімкни показ розширень

  • Windows 11: у Провіднику вгорі «Переглянути» (Перегляд) → «Показати» → постав галочку «Розширення імен файлів».
  • Windows 10: у Провіднику вкладка «Вигляд» → галочка «Розширення імен файлів».

Тепер усі файли показуються з повними іменами. Залиш це увімкненим назавжди.

Байти, кілобайти, гігабайти

Розмір файлу вимірюють у байтах. Пам'ятаєш, байт — це 8 бітів. Байтів у файлах багато, тому вживають більші одиниці. У Windows кожна наступна в 1024 рази більша за попередню (1024 = 2¹⁰, знову степінь двійки):

ОдиницяСкількиЩо приблизно таке важить
1 байт8 бітіводна латинська літера
1 КБ (кілобайт)1024 байтипів сторінки тексту
1 МБ (мегабайт)1024 КБхвилина музики в MP3
1 ГБ (гігабайт)1024 МБгодина відео
1 ТБ (терабайт)1024 ГБвеликий диск

    Крок 5 · практика · 15 хв

    Наводимо лад: папка для курсу

    Програмісти завжди тримають файли проєкту в одному місці. Створи собі таку структуру в «Документах»:

    Documents
└── Інформатика
    ├── Python        ← сюди зберігай програми з занять
    ├── Нотатки       ← конспекти, якщо пишеш
    └── Проєкти       ← твої власні ідеї

    Як створити папку: у Провіднику Ctrl + Shift + N, напиши назву, Enter. Потім збережи туди хоча б одну програму з попередніх занять (у IDLE: File → Save As).

    Видалення. Видалений файл (клавіша Delete) спершу потрапляє в Кошик, звідки його можна повернути. А Shift + Delete видаляє одразу, без Кошика. Будь з цим обережний.

    Пошук файлів

    Відкрий папку «Документи» і надрукуй у полі пошуку праворуч угорі *.py. Зірочка означає «будь-що», тож Windows знайде всі файли з розширенням .py, тобто всі твої програми на Python, в усіх вкладених папках.

    Перший погляд у командний рядок

    Ще до Провідника з мишкою люди працювали з файлами, друкуючи команди. Це досі вміють усі програмісти. Спробуй:

    1. Win + R, напиши cmd, Enter. Відкриється чорне вікно, командний рядок.
    2. Напиши cd Documents і Enter: ти «зайшов» у папку Документи. Шлях видно ліворуч.
    3. Напиши dir і Enter: список файлів і папок з розмірами.
    4. Напиши tree Інформатика /f і Enter: дерево твоєї папки курсу, як у кроці 5!
    5. Закрий вікно або напиши exit.

    ★ Бонус на Python

    Програма показує, що лежить у папці і скільки важить кожен файл. Збережи її в папку Інформатика\Python і запусти:

    import os

folder = os.path.expanduser("~\\Documents")   # ~ означає твою папку користувача
if not os.path.isdir(folder):                  # якщо Документи синхронізуються з OneDrive
    folder = os.path.expanduser("~\\OneDrive\\Documents")
print("Папка:", folder)

for name in os.listdir(folder):
    path = os.path.join(folder, name)
    if os.path.isfile(path):
        print("файл ", name, os.path.getsize(path) // 1024, "КБ")
    else:
        print("папка", name)

    Спробуй замінити Documents на Downloads чи Pictures.
